## 📝 Краткое содержание решений

### 1. Анализ требований (Корзина)
В ходе анализа фрагмента технического задания были выявлены логические противоречия (конфликт лимитов, двойное удаление товара, противоречие фиксации цены) и недочеты (размытые формулировки рекламы).  
✅ **Результат:** Предложена исправленная, логически завершенная версия ТЗ, а также составлен список уточняющих вопросов для продукт-менеджера.

### 2. Проектирование API (Экран выбора магазинов)
Разработан REST-эндпоинт для получения списка магазинов-партнеров на основе геолокации пользователя.  
✅ **Результат:** Описан пример запроса с параметрами (`lat`, `lng`) и структура JSON-ответа, полностью соответствующая предоставленному мобильному макету (с учетом поля `url` для перехода по клику).

### 3. Архитектура PUSH-уведомлений
Спроектирована высокоуровневая архитектура асинхронной доставки уведомлений в условиях микросервисной среды.  
✅ **Результат:** Предложена событийно-ориентированная схема с использованием очередей сообщений (Kafka/RabbitMQ), слоя валидации, проверки пользовательских настроек (тихие часы, подписки) и адаптеров для FCM (Android) и APNs (iOS). Схема включает механизмы ретраев, Dead Letter Queue и мониторинга.
